### CSS
CSS används för att ändra webbläsarens standardstil, vi gick igenom 3 sätt att använda CSS

**Inline**
  <p>style="color: blue;"Klockan är 12:00</p> 

**Internal** 
<style>.task-item {margin-bottom: 1 rem;}
</style>
**External**
<link  rel="stylesheet" href="styles.css" />
